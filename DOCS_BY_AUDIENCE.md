# Documentation by Audience

This repo has three primary readers. Each reader should start with a different set of files so the path stays short and precise.

## If You Are New Here
Read:
1. `README.md`
2. `START_HERE.md`
3. `GLOSSARY.md`

Use this path if you want the simplest explanation of what the repo is and how the harness works.

1. `WORKFLOW_CHEAT_SHEET.md`
2. `REPO_MAP.md`
3. `CONTRIBUTING.md`

## Writing Rules
- Treat this file as the canonical routing page.
- Do not repeat full audience tables in other docs.
- In audience-specific docs, list only the next few files a reader needs.
- Keep doc titles and link targets stable.
