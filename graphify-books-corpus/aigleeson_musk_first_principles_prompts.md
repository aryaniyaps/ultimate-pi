# Musk-style first-principles prompts (Gleeson thread, Nov 2025)

Curated summary of [@aigleeson](https://x.com/aigleeson)’s thread: using Elon Musk–style reasoning as **repeatable AI prompts**—physics framing, stripping assumptions, pre-mortems, and leverage.

**Original post (X):** https://x.com/aigleeson/status/1994035862372536811  
**Thread Reader (readable archive):** https://threadreaderapp.com/thread/1994035862372536811.html

## Framing

Musk is described as stripping problems to **objective reality** (“physics”), refusing **industry copy-paste**, and designing from **ideal-then-constrain** and **pre-mortem** thinking. The thread packages that as **15 numbered prompts** plus a **stacked meta-prompt** and a **single “mind shift” question**.

## The 15 prompts

1. **What are the physics of this problem?** — Hard constraints, real forces, bottlenecks.
2. **If I couldn’t rely on existing assumptions, how would I solve this?** — Break “invisible cages.”
3. **What are the problem’s fundamental components?** — Atomic decomposition.
4. **What would the optimal solution look if cost didn’t exist?** — Ideate before constraints.
5. **If I were forced to cut 90% of this, what would remain?** — Brutal prioritization.
6. **If this failed completely, what would be the root cause?** — Pre-mortem / failure modes.
7. **What would a solution look like if I ignored industry norms?** — Non-obvious paths.
8. **What part is actually impossible vs only feels impossible?** — Physics vs fear.
9. **What is the minimum viable breakthrough?** — Foundational leap, not MVP.
10. **If I restarted this project today knowing what I know, what would I build?** — Clean slate.
11. **What hidden constraints am I not questioning?** — Self-imposed ceilings.
12. **How would I solve this if I only cared about physics, not politics?** — Uncompromised version first.
13. **If I had to achieve this 10× faster, what would I do?** — Speed forcing function.
14. **What would this look like if it had to scale to millions?** — Orders-of-magnitude design.
15. **Which part of this solution creates the most leverage?** — Multiplier focus.

## Stacked meta-prompt (verbatim gist)

> Break my problem into fundamental truths, strip all assumptions, find the optimal solution, identify hidden constraints, and rebuild the idea from first principles.

## Mind-shift question (verbatim gist)

> If I rebuilt this from raw truth, what would it become?

## Epilogue note

The thread contrasts **physicist-style** clarity with **pattern-matching** LLMs and argues combining both improves judgment. It ends with a newsletter CTA (*The Shift*); that promotional block is **not** part of the reasoning framework itself.
